# K-Pattern Radar

국내 증시 대표 20종목의 추세와 위험을 초보자도 읽을 수 있는 문장으로 설명하는
무료 공개 앱입니다. 매수 추천 도구가 아니라, **무엇을 더 확인해야 하는지**를
알려주는 판단 보조 도구입니다.

## 이 폴더에 들어 있는 것

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `update_market.py` | 시세 수집, 지표 계산, 판단 생성 |
| `live-data.json` | 가장 최근에 만들어진 시세·판단 자료 |
| `history.json` | 날짜별 판단 기록과 이후 성과 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈화면 설치와 오프라인 열람 |
| `.github/workflows/live-market.yml` | 평일 장중 자동 갱신 |
| `.nojekyll` | GitHub Pages 빌드 단순화 |

외부 자바스크립트 라이브러리도, 빌드 과정도 없습니다. 파일을 그대로 올리면 됩니다.

## 올리는 방법

1. GitHub에서 **공개(Public) 저장소**를 새로 만듭니다.
2. 이 폴더 안의 모든 파일을 `.github` 폴더까지 포함해 저장소 최상위에 올립니다.
   웹 화면에서 `Add file → Upload files`로 폴더째 끌어다 놓으면 하위 폴더 경로도
   그대로 유지됩니다.
3. **Settings → Pages → Build and deployment → Source**를
   `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)`로 둡니다.
4. **Actions** 탭에서 `Refresh market data`를 열고 `Run workflow`를 한 번 누릅니다.
   이때 처음으로 진짜 시세가 수집됩니다.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속합니다.

처음 올린 `live-data.json`은 화면 점검용 **샘플**입니다. 실제 시세가 아니므로
앱 위쪽에 빨간 경고띠가 뜹니다. 4번을 실행하면 실제 시세로 바뀌고 경고띠가 사라집니다.

## 휴대전화에 설치하기

접속한 뒤 아이폰은 공유 버튼 → `홈 화면에 추가`, 안드로이드는 메뉴 → `앱 설치`를
누르면 아이콘이 생깁니다. 지하철이나 통신이 끊긴 곳에서도 앱이 열리고,
마지막으로 받아 둔 자료를 보여줍니다.

## 갱신 주기와 그 한계

평일 한국시간 09:05부터 15:45까지 20분 간격, 그리고 장 마감 직후 한 번 더
갱신합니다. 다만 GitHub의 예약 실행은 **정시를 보장하지 않습니다.** 혼잡할 때는
5분에서 30분까지 밀리고, 아주 가끔은 한 번을 건너뛰기도 합니다. 그래서 이 앱은
"실시간"이라고 말하지 않고, 화면에 항상 "몇 분 전 자료"인지 적습니다.

장중에 3시간 넘게 갱신이 없으면 판단 표시를 스스로 멈추고 빨간 경고를 띄웁니다.

저장소에 60일 넘게 아무 활동이 없으면 GitHub가 예약 실행을 자동으로 꺼 버립니다.
자동 커밋이 계속 쌓이므로 보통은 문제가 없지만, 어느 날 갑자기 갱신이 멈췄다면
Actions 탭에서 `Enable workflow`를 눌러 주세요.

## 시세 출처

무료 공개 시세만 사용하며 별도 신청이나 키 발급이 필요 없습니다.
야후 파이낸스를 먼저 시도하고, 실패하면 네이버 금융, 그다음 Stooq 순으로
다시 시도합니다. 어느 경로로 받았는지는 앱의 `데이터 상태` 화면에 표시됩니다.

공급자에 따라 15~20분 지연될 수 있습니다. 거래소 실시간 시세가 아닙니다.
**실제 주문 직전에는 반드시 증권사 앱의 호가와 공시를 다시 확인하세요.**

수집 중 문제가 생기면 이렇게 대응합니다.

- 코스피·코스닥 중 하나라도 실패하면 파일을 아예 갱신하지 않습니다.
  잘못된 자료를 새 자료인 척 내놓지 않기 위해서입니다.
- 종목 20개 중 12개 미만만 모이면 역시 갱신하지 않습니다.
- 일부 종목만 실패하면 갱신은 하되 `데이터 상태` 화면에 실패 목록을 공개합니다.

## 종목을 바꾸려면

`update_market.py` 위쪽의 `UNIVERSE` 목록만 고치면 됩니다. 종목코드, 이름,
시장(KOSPI 또는 KOSDAQ), 업종 네 가지를 적으면 됩니다.

```python
{"code": "005930", "name": "삼성전자", "market": "KOSPI", "sector": "반도체"},
```

고친 뒤 Actions에서 워크플로를 한 번 실행하면 반영됩니다.

## 판단 점수는 어떻게 나오는가

추세 25점, 상승 힘 20점, 시장 대비 강도 15점, 거래량 15점, 가격 패턴 15점,
손익비 10점을 더해 100점으로 만듭니다. 75점 이상이면서 손익비 1.5 이상,
거래량이 충분하고 상승 신호가 확인될 때만 `매수 검토` 후보가 됩니다.
시장 자체가 하락 우위이면 기준을 85점으로 올립니다.

종목 상세 화면에서 보유 여부와 평균 매입가를 넣으면 같은 종목도
`보유 유지`, `비중 축소 검토`, `매도·손절 검토`로 다시 계산됩니다.
이 값은 해당 브라우저에만 저장되고 어디로도 전송되지 않습니다.

### 솔직하게 밝혀 두는 한계

이 배점은 **백테스트로 검증된 값이 아닙니다.** 합리적으로 보이도록 정한 숫자이며,
누군가의 수익을 보장하지 않습니다. 그래서 `판단 기록` 화면을 넣었습니다.
매일의 판단을 저장해 두고 그 뒤 주가가 어떻게 되었는지 그대로 보여줍니다.
성적이 나쁘면 나쁜 대로 나옵니다. 몇 달 지켜보고 믿을지 말지 직접 정하시면 됩니다.

표본이 30건도 되지 않을 때의 승률은 실력이 아니라 우연일 가능성이 큽니다.

가격과 거래량만 봅니다. 기업의 실적, 돌발 공시, 환율·금리 충격, 정책 변화는
전혀 반영하지 못합니다. 자동 주문이나 계좌 접근 기능은 없습니다.

이 앱은 교육·정보 제공 목적의 판단 보조 도구입니다. 투자자문이 아니며
최종 판단과 책임은 사용자 본인에게 있습니다.

## 내 컴퓨터에서 미리 보려면

```bash
pip install requests
python update_market.py          # 실제 시세 수집
python -m http.server 8000       # http://localhost:8000 접속
```

`python update_market.py --sample` 을 쓰면 인터넷 없이 화면만 점검할 수 있습니다.
