# K-Pattern Radar

국내 증시의 최신 시장 흐름과 대표 종목을 분석해 `매수 검토`, `관망`,
`보유 유지`, `비중 축소 검토`, `매도·손절 검토`로 설명하는 무료 공개
앱입니다. 주식 초보자도 판단 근거와 위험을 함께 읽을 수 있도록 만들었습니다.

## 포함 파일

| 파일 | 역할 |
|---|---|
| `index.html` | GitHub Pages 앱 전체 화면과 AI 판단 UI |
| `live-data.json` | 가장 최근에 생성된 시장·종목 데이터 |
| `update_market.py` | 시세 수집과 지표·AI 판단 계산 |
| `.github/workflows/live-market.yml` | 장중 5분 자동 갱신과 Pages 배포 |
| `README.md` | 설치·운영 안내 |

외부 JavaScript 라이브러리나 별도 빌드 과정은 없습니다.

## GitHub에 올리기

1. 이 폴더 안의 파일과 `.github` 폴더를 새 GitHub 공개 저장소 최상위에
   업로드합니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**를
   **GitHub Actions**로 선택합니다.
3. **Actions** 탭에서 `Refresh live market dashboard`를 한 번 수동
   실행합니다.
4. 작업이 완료되면 GitHub Pages 주소로 접속합니다.

평일 09:00~16:55 한국시간에 약 5분 간격으로 최신 데이터를 다시 만들고
배포합니다. 브라우저는 `live-data.json`을 60초마다 재확인합니다. GitHub
Actions의 실행·배포 대기 때문에 정확히 5분마다 반영된다고 보장되지는
않습니다.

## 데이터 모드

### 무료 공개 모드

추가 설정이 없으면 Yahoo Finance 공개 시세를 이용합니다. 데이터 공급자에
따라 15분 이상 지연될 수 있으며 앱 화면에 `무료 공개 지연 시세`라고
표시됩니다.

### 한국투자증권 공식 시세 모드

더 정확한 현재가가 필요하면 한국투자증권 Open API에서 읽기 전용 앱 키를
발급받고 다음 값을 GitHub 저장소의 **Settings → Secrets and variables
→ Actions**에 등록합니다.

- `KIS_APP_KEY`
- `KIS_APP_SECRET`

그다음 Actions 작업을 실행하면 종목 현재가는 한국투자증권 공식 API,
과거 기술지표는 공개 과거자료를 사용합니다. 비밀키는 GitHub Actions
서버에서만 사용되고 웹페이지나 JSON에 저장되지 않습니다.

## 정확성 안전장치

- KOSPI와 KOSDAQ을 서로 다른 공식 심볼로 수집합니다.
- 현재값, 전일 종가, 등락률, 원본 시세 시각을 함께 저장합니다.
- 당일 거래량은 일봉 누적 거래량과 분봉 거래량 합계를 비교합니다.
- 지수 두 개 중 하나라도 수집에 실패하면 새 데이터 파일을 만들지 않습니다.
- 장중 데이터가 20분 이상 오래되면 매수·매도 판단을 자동 중지합니다.
- 일부 종목 수집 실패는 화면의 데이터 상태 메뉴에 공개합니다.
- 자동 주문과 계좌 접근 기능은 없습니다.

## AI 판단 원리

이 앱에서 말하는 AI는 근거를 확인할 수 있는 정량 판단 엔진입니다.

- 추세 25점
- 20일 상승 힘과 RSI 20점
- 시장 대비 상대강도 15점
- 거래량 15점
- 돌파·눌림목·추세 패턴 15점
- 진입가·손절가·목표가 손익비 10점

75점 이상, 손익비 1.5 이상, 적정 거래량과 유효 상승 신호가 함께 확인될
때만 `매수 검토` 후보가 됩니다. RSI 과열, 시장 위험회피, 하락 추세가
확인되면 관망하거나 신규 매수에서 제외합니다.

종목 상세창에서 `보유 중`과 평균 매입가를 입력하면 판단이 보유 유지,
비중 축소, 매도·손절 검토로 다시 계산됩니다. 이 개인 입력값은 해당
브라우저에만 저장됩니다.

## 중요한 한계

KRX 실시간 시장정보는 라이선스가 필요한 상품입니다. 무료 공개 모드는
실시간에 가까운 자동 갱신을 제공하지만 거래소 직접 실시간 데이터라고
표현하지 않습니다. 실제 주문 직전에는 반드시 증권사 앱의 최신 호가와
기업 공시를 다시 확인해야 합니다.

이 앱은 교육·정보 제공 목적의 판단 보조 도구입니다. 투자자문, 자동 주문,
수익 보장을 제공하지 않으며 최종 투자 판단과 책임은 사용자에게 있습니다.
