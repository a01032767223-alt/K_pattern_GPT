# K-Pattern Radar

국내 증시 **코스피·코스닥 57종목**(코스피 36 · 코스닥 21, 업종별 3종목 이상)의 추세와 위험을 초보자도 읽을 수 있는
문장으로 설명하는 무료 공개 앱입니다. 매수 추천 도구가 아니라, **무엇을 더 확인해야 하는지**를
알려주는 판단 보조 도구입니다.

## 이 폴더에 들어 있는 것

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `update_market.py` | 시세 수집, 지표 계산, 판단 생성 |
| `live-data.json` | 가장 최근에 만들어진 시세·판단·미국 시장 자료 |
| `history.json` | 날짜별 판단 기록과 이후 성과 |
| `intraday.json` | 종목별 6개 시간대 캔들(하루 두 번만 갱신) |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈화면 설치와 오프라인 열람 |
| `.github/workflows/live-market.yml` | 하루 세 차례(08:20 · 장중 20분 · 15:50) 자동 갱신 |
| `.nojekyll` | GitHub Pages 빌드 단순화 |

외부 자바스크립트 라이브러리는 없으며(글꼴만 구글 폰트를 불러옵니다), 빌드 과정도 없습니다.
파일을 그대로 올리면 됩니다.

## 올리는 방법

1. GitHub에서 **공개(Public) 저장소**를 새로 만듭니다.
2. 이 폴더 안의 모든 파일을 `.github` 폴더까지 포함해 저장소 최상위에 올립니다.
3. **Settings → Pages → Build and deployment → Source**를
   `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)`로 둡니다.
4. **Actions** 탭에서 `Refresh market data`를 열고 `Run workflow`를 한 번 누릅니다.
   이때 처음으로 진짜 시세가 수집됩니다.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속합니다.

처음 올린 `live-data.json`은 화면 점검용 **샘플**입니다. 4번을 실행하면 실제 시세로 바뀝니다.

## 휴대전화에 설치하기

접속한 뒤 아이폰은 공유 버튼 → `홈 화면에 추가`, 안드로이드는 메뉴 → `앱 설치`를
누르면 아이콘이 생깁니다. 지하철이나 통신이 끊긴 곳에서도 앱이 열리고,
마지막으로 받아 둔 자료를 보여줍니다.

## 갱신 주기와 그 한계

**점수·판단**은 평일 한국시간 09:05부터 15:45까지 20분 간격으로 갱신됩니다.
**시간봉 차트와 전일 미국 시장 요약**은 08:20(장 시작 전)과 15:50(장 마감 후) 하루
두 번만 갱신됩니다. 57종목의 시간봉을 20분마다 받으면 API 부담과 차단 위험이
커지기 때문에, 차트만 갱신 빈도를 낮췄습니다.

GitHub의 예약 실행은 정시를 보장하지 않아 5~30분 밀릴 수 있습니다. 그래서 화면에
항상 "몇 분 전 자료"인지 적습니다. 장중에 3시간 넘게 갱신이 없으면 판단 표시를
스스로 멈춥니다.

저장소에 60일 넘게 아무 활동이 없으면 GitHub가 예약 실행을 자동으로 꺼 버립니다.
자동 커밋이 계속 쌓이므로 보통은 문제가 없지만, 어느 날 갑자기 갱신이 멈췄다면
Actions 탭에서 `Enable workflow`를 눌러 주세요.

## 시세 출처와 순서

무료 공개 시세만 사용합니다. GitHub Actions 서버 IP가 야후 파이낸스에 자주 차단당하는
사례가 있어, **네이버 금융 → Stooq → 야후 파이낸스** 순으로 시도하도록 구성했습니다.
지수(코스피·코스닥)는 네이버의 지수 심볼(KOSPI/KOSDAQ)로 먼저 조회하고, 실패하면
야후로 넘어갑니다. 원/달러 환율은 야후에서만 가져오며, 실패해도 다른 자료 갱신을 막지 않습니다.

공급자에 따라 15~20분 지연될 수 있습니다. 거래소 실시간 시세가 아닙니다.
**실제 주문 직전에는 반드시 증권사 앱의 호가와 공시를 다시 확인하세요.**

  오늘의 판단 요약, 전일 대비 신호 변화, 지금 강한 섹터, 거래대금 상위
- **종목별 판단**: 코스피/코스닥 세그먼트, 섹터별로 묶은 표, 52주 위치 막대, 상세 모달

S&P500·나스닥·다우·VIX(공포지수)·美 10년물 국채금리·업종 대표 ETF 6종(반도체 SMH,

**중요:** 이 요약은 생성형 AI를 그때그때 호출해 쓴 글이 아닙니다. 계산된 수치를
정해진 규칙으로 문장에 끼워 넣는 방식이며, 이 앱의 다른 모든 판단과 같은 원리입니다.
그 이유는 두 가지입니다. 매번 유료 AI API를 부르면 이 앱이 더 이상 무료·키 없이
동작하지 못하고, 무엇보다 "AI가 의견을 내는 게 아니라 계산 규칙으로 설명한다"는
이 앱의 원칙이 깨지기 때문입니다. 코스피·코스닥 종목의 100점 점수에는 반영되지
않는 배경 정보이며, 반도체 ETF가 강하면 삼성전자·SK하이닉스 등에 우호적일 수
있다는 식의 조건부 문장만 만듭니다.

## 캔들 차트와 1차·2차 목표가

종목 상세 화면에서 **캔들(봉) 차트**에 진입 구간(연두색 띠), 손절 기준(파란 점선),
1차 목표(빨간 실선), 2차 목표(빨간 점선), 현재가(검은 선)를 겹쳐 보여줍니다. 양봉은
빨강, 음봉은 파랑으로 한국 시장 관례를 따르고, 아래에 거래량 막대도 함께 그립니다.
참고선 라벨은 오른쪽 여백에 배지로 붙여 캔들과 겹치지 않게 했습니다. **손절은 항상
현재가·진입가 아래**로 계산되도록 안전장치를 넣어, 차트에서 위아래가 뒤바뀌어 보이는
일이 없게 했습니다.

작은 화면에서는 최근 60개 캔들만 크게 보여주고, **차트를 터치하면 최근 120개 캔들의
큰 화면으로 확대**됩니다(별도 브라우저 창이 아니라 화면 안 전체화면 방식이라 모바일
팝업 차단에 걸리지 않습니다). 확대 화면에서도 6개 시간대를 그대로 전환할 수 있습니다.

1차 목표는 변동성 기준으로 보수적으로 잡은 이익실현 지점이고, 2차 목표는 추세가
이어졌을 때의 확장 목표(1차까지 보상폭의 1.8배)입니다. 1차에서 일부 정리하고 나머지를
2차까지 지켜보는 방법이 흔히 쓰입니다.

**시간대는 6종** — 15분·30분·1시간·4시간·일봉·주봉을 탭으로 전환합니다. 큰 흐름은
일봉·주봉으로, 단기 진입 타이밍은 15분·1시간봉으로 나눠 보면 좋습니다. 4시간봉은
야후가 직접 주지 않아 1시간봉을 4개씩 묶어 만듭니다.

데이터 출처에 제약이 있습니다. **분봉(15·30·60분·4시간)은 야후 파이낸스에서만** 받을
수 있고, 무료 API 특성상 15·30분봉은 최근 약 60일까지만 제공됩니다. **일봉·주봉은
야후가 막히면 네이버로 대체**됩니다. 그래서 야후 접근이 막힌 환경에서는 분봉 탭이
비활성화되고 일봉·주봉만 보일 수 있습니다.

차트는 57종목 전체를 20분마다 받으면 API 부담과 차단 위험이 커서 하루 두 번(08:20,
15:50)만 갱신됩니다. 종목 점수·판단은 이와 별개로 20분마다 최신입니다. 자료가 아직
없는 시간대는 탭이 흐리게 비활성화되고, 안내 문구가 뜹니다.

## 코스피·코스닥 지수 차트

홈 화면의 코스피·코스닥 카드를 누르면 지수도 종목과 같은 6개 시간대 캔들 차트로
열립니다. 지수는 사고파는 대상이 아니라서 진입·손절·목표선 대신 **20·60·120일
이동평균선**을 그려 추세를 보여줍니다. 아래의 '차트 읽기' 해설도 함께 나옵니다.

참고로 지수의 거래량은 구성종목 거래량의 합이라, 개별 종목만큼 신호가 선명하지
않습니다. 지수 화면에서는 거래량 해석을 조금 약하게 읽는 편이 좋습니다.

## '차트 읽기' — 여덟 가지 해설

차트 아래에 캔들 배열만 보고 계산한 해설이 신호등(초록·주황·회색)과 함께 나옵니다.
항목을 누르면 근거 문장이 펼쳐집니다. **시간대 탭을 바꾸면 해설도 그 시간대 기준으로
다시 계산됩니다.**

| 항목 | 무엇을 보는가 | 신뢰도 |
|---|---|---|
| 거래량 동반 반등 | 저점에서 올라올 때 거래가 함께 늘었는지 | 높음 |
| 박스권 상단 돌파 | 좁은 구간에 갇혀 있었는지, 그 위쪽 벽을 넘었는지 | 높음 |
| 전고점 돌파 | 위쪽에 남은 스윙 고점(저항)까지의 거리 | 높음 |
| 되돌림 폭 | 오른 만큼 중 얼마나 다시 내려왔는지 | 중간 |
| 저점 수준 | 저점이 계단식으로 높아지는지 낮아지는지 | 높음 |
| 매물대 | 가격대별 거래량 분포로 본 지지·저항 | 중간 |
| 이동평균 배열 | 정배열·역배열·혼조 | 높음 |
| 채널 이탈 | 추세선 위아래로 얼마나 벌어졌는지 | **낮음(참고용)** |

**채널 이탈만 흐리게 표시한 이유**가 있습니다. 채널은 어느 구간과 어느 고점을 잡느냐에
따라 결과가 달라져 사람마다 다르게 그립니다. 매매 근거로 쓰기엔 자의성이 커서, 분위기
참고용으로만 약하게 넣었습니다.

**되돌림 폭**의 38.2%·50%·61.8%는 많이 쓰이는 숫자라 알려주지만, 그 자리에서 반드시
반등한다는 근거는 없습니다. **매물대**는 실제 체결 단가 분포가 아니라 봉 자료로 만든
근사치입니다(진짜 매물대는 증권사만 가진 체결 자료가 있어야 합니다).

여덟 항목은 서로 엇갈릴 때가 많습니다. 여러 항목이 같은 방향을 가리킬 때가 그나마
신뢰도가 높고, 짧은 시간대(15·30분)일수록 신호가 자주 뒤집힙니다.

차트에는 이 밖에 **매물대 막대**(오른쪽 회색 가로 막대)와 **거래량 급증 표시**(평균의
2배가 넘는 봉에 점)를 함께 그립니다.

이 여덟 가지는 모두 **100점 점수 계산에는 넣지 않았습니다.** 검증되지 않은 지표를
점수에 섞으면 '판단 기록'으로 쌓아온 검증 자료와 연속성이 끊기기 때문입니다.

## 판단 점수는 어떻게 나오는가

추세 25점, 상승 힘 20점, 시장 대비 강도 15점, 거래량 15점, 가격 패턴 15점,
손익비 10점을 더해 100점으로 만듭니다. 75점 이상(시장이 약할 때는 85점 이상)이면서
손익비 1.5 이상, 거래량이 충분하고 상승 신호가 확인될 때만 `매수 검토` 후보가 됩니다.

**기준에 가깝지만 못 미친 경우**는 '관망·근접'으로 따로 표시해, 문턱 바로 아래에서
칼같이 '관망'으로만 나오는 문제를 줄였습니다. 매수 후보의 확신도는 거래량과 점수 여유에
따라 낮음/보통/높음 3단계로 나뉩니다. 52주 신고가 부근인데 거래량 동반 돌파가 아직 없으면
위험 문구에 자동으로 추가됩니다.

52주 위치, 섹터 평균, 시장 폭, 거래대금, 환율은 **100점 계산에는 들어가지 않는 참고
지표**입니다. 종목 점수와 시장 분위기가 엇갈릴 때 더 보수적으로 판단하도록 돕는
배경 정보로 넣었습니다.

종목 상세 화면에서 보유 여부와 평균 매입가를 넣으면 같은 종목도
`보유 유지`, `비중 축소 검토`, `매도·손절 검토`로 다시 계산됩니다.
이 값은 해당 브라우저에만 저장되고 어디로도 전송되지 않습니다.

### 솔직하게 밝혀 두는 한계

이 배점은 **백테스트로 검증된 값이 아닙니다.** 합리적으로 보이도록 정한 숫자이며,
누군가의 수익을 보장하지 않습니다. 그래서 `판단 기록` 화면을 넣었습니다.
매일의 판단을 저장해 두고 그 뒤 주가가 어떻게 되었는지 그대로 보여줍니다.
표본이 30건도 되지 않을 때의 승률은 실력이 아니라 우연일 가능성이 큽니다.

가격과 거래량만 봅니다. 기업의 실적, 돌발 공시, 환율·금리 충격, 정책 변화는
전혀 반영하지 못합니다. 자동 주문이나 계좌 접근 기능은 없습니다.

이 앱은 교육·정보 제공 목적의 판단 보조 도구입니다. 투자자문이 아니며
최종 판단과 책임은 사용자 본인에게 있습니다.
