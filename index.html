어려운 지표를 외우기보다 어떤 질문에 답하는 숫자인지 이해하세요.

매수 검토는 ‘당장 매수’가 아닙니다

좋은 조건이 겹친 후보라는 뜻입니다. 제시된 진입 구간에 가격이 왔는지, 공시나 실적 발표가 임박했는지 확인한 뒤 나눠서 접근하세요.

관망도 중요한 투자 행동입니다

확신이 낮거나 가격이 너무 오른 경우 돈을 지키는 선택입니다. 기회를 놓친 것이 아니라 더 나은 가격과 근거를 기다리는 것입니다.

보유자와 미보유자의 판단은 다릅니다

하락 종목은 미보유자에게 ‘신규 매수 제외’, 보유자에게는 평균단가와 손절선을 고려한 ‘매도·손절 검토’가 됩니다.

처음 투자할 때의 순서

  1. 생활비와 비상금을 제외합니다.
  2. 시장 위험 상태를 확인합니다.
  3. 종목의 공시와 실적을 확인합니다.
  4. 진입가·손절가·목표가를 적습니다.
  5. 한 번에 전액을 사지 않습니다.

Transparent methodology

AI는 무엇을 보고 판단하나요?

외부 생성형 AI의 막연한 의견이 아니라, 확인 가능한 정량 규칙을 사용합니다.

1. 시장 환경

KOSPI·KOSDAQ 현재값과 20·60·120일 이동평균 배열을 비교합니다. 지수가 세 평균선 아래에 있으면 위험회피로 보고 신규 매수를 엄격하게 제한합니다.

2. 추세 · 25점

현재가와 단기·중기·장기 이동평균선의 순서를 평가합니다. 가격이 모든 평균선 위이고 단기선이 장기선보다 높을수록 좋은 점수를 줍니다.

3. 모멘텀 · 20점

20일 수익률과 RSI를 함께 봅니다. 상승하더라도 RSI가 지나치게 높으면 과열로 판단해 추격 매수를 막습니다.

4. 시장 대비 강도 · 15점

종목의 20일 수익률에서 해당 시장 지수 수익률을 뺍니다. 지수보다 더 강하게 오른 종목을 우선합니다.

5. 거래량 · 15점

당일 누적 거래량을 최근 20일 평균과 비교합니다. 가격 상승에 평소보다 많은 거래가 동반될 때 신뢰도를 높입니다.

6. 패턴·손익비 · 25점

돌파, 눌림목, 상승 정렬을 확인하고 진입·손절·목표가로 손익비를 계산합니다. 손익비 1.5 미만은 매수 후보에서 제외합니다.

!한계: 이 판단은 가격·거래량 중심이며 기업가치, 돌발공시, 정치·환율·금리 충격을 모두 예측하지 못합니다. ‘AI 판단’은 투자자문이나 수익 보장이 아닙니다.

무료 공개 모드

API 키 없이 Yahoo Finance 공개 시세를 사용합니다. GitHub Actions가 장중 5분마다 새 자료를 만들지만 공급자·배포 지연이 있을 수 있습니다.

  • 누구나 무료 사용
  • 지연 가능성을 화면에 표시
  • 오래되면 AI 판단 자동 중단

공식 시세 연결 · 권장

한국투자증권 Open API 키를 GitHub Secrets에 넣으면 종목 현재가가 공식 읽기 전용 API로 전환됩니다. 키는 웹페이지에 노출되지 않습니다.

  1. 저장소 Settings → Secrets and variables → Actions
  2. KIS_APP_KEY와 KIS_APP_SECRET 등록
  3. Actions에서 Refresh live market dashboard 실행
자동 갱신: 평일 09:00~16:55 (한국시간), 약 5분 간격 브라우저 확인: 60초마다 live-data.json 재조회 정확성 보호: 장중 20분 이상 오래된 자료는 AI 판단 차단 주문 기능: 없음 (읽기 전용)
